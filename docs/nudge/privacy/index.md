**돌돌소프트(대표 신기록, 이하 “운영자”)**는 Nudge에서 처리하는 정보와 그 이용·보관·삭제 방법을 다음과 같이 안내합니다. 이 방침은 Nudge 앱과 이 사이트의 Nudge 정책 페이지에 적용됩니다. 다른 서비스의 정책은 해당 서비스 페이지에서 별도로 확인할 수 있습니다.

Nudge는 자체 회원가입 없이 이용합니다. **생활 기록과 앱 선택 정보는 기기에서 처리하며 운영자의 서버로 전송하지 않습니다.** 다만 Apple 서비스와의 통신, 이메일 문의, 정책 사이트 방문 시 처리되는 정보가 있으므로 모든 개인정보 처리가 없다는 뜻은 아닙니다.

생활 기록은 실제 주문·식사·수면·건강 상태나 앱 사용 시간을 측정한 정보가 아닙니다. 예약 등록 기록도 실제 제한이 정각에 성공했음을 보장하는 기록은 아닙니다.

앱과 수면 기능 확장 프로그램은 기능 수행에 필요한 설정을 같은 기기에서 공유합니다. 자체 계정 서버나 기기 간 클라우드 동기화를 제공하지 않습니다. 생활 기록 파일과 로컬 구독 상태 파일은 앱의 백업 대상에서 제외하도록 설정하지만, 모든 앱 설정과 Apple의 시스템 데이터까지 동일하게 제외된다는 의미는 아닙니다.

## 2. 로컬 기록의 삭제와 권한 관리

앱의 **설정 → 기록 초기화**에서 생활 통계와 현재 월 합계를 삭제할 수 있습니다. 초기화 후 새 행동부터 다시 기록됩니다. 이 동작은 앱 선택·시간·단축어 실행 이력·구독 정보를 함께 지우는 기능이 아닙니다. 단축어 실행 이력은 해당 설정의 **실행 기록 지우기**에서 관리할 수 있습니다.

Screen Time 권한은 iPhone 설정에서 관리할 수 있으며, 권한을 해제하면 해당 권한에 의존하는 기능을 사용할 수 없습니다. 앱 삭제는 구독 취소가 아니며, Apple의 구매 기록·단축어 자동화·기기 백업·이메일 문의 기록을 함께 삭제하지 않습니다. 단축어 자동화는 단축어 앱에서 직접 관리해야 합니다.

기기에만 있는 생활 기록은 운영자가 서버에서 조회하거나 대신 복구할 수 없습니다. 기기 이전에 따른 생활 기록 이전 기능도 제공하지 않습니다. 앱이 실행되지 않는 동안에도 만료 시각에 맞춰 모든 오래된 자료가 즉시 삭제된다고 보장하지는 않습니다.

## 3. Apple 서비스와의 통신

Nudge는 다음 기능에 Apple 서비스를 이용합니다.

- **App Store 결제·구독:** Apple이 결제와 구독 관리를 처리하고, 앱은 구독 권한 확인에 필요한 거래 정보를 받습니다. 운영자는 앱에서 카드번호·결제 수단 비밀번호를 수집하지 않습니다. Apple 자체의 결제·계정 기록은 Apple의 보관·처리 기준에 따릅니다.
- **앱 아이콘 조회:** 표시할 아이콘을 받기 위해 조회 대상의 App Store 식별자와 한국 스토어 구분을 Apple의 앱 정보 조회 서비스에 보내고 이미지 서버에 연결합니다. 기기 통신 과정에서 IP 주소 등 네트워크 정보가 해당 서비스에 전달될 수 있습니다. 이는 이용자의 전체 설치 앱 목록이나 생활 기록을 전송하는 기능이 아닙니다.
- **단축어 연결:** 이용자가 단축어 공유 링크를 여는 경우 Apple의 iCloud·단축어 서비스로 이동합니다. 외부 페이지 이용에는 해당 서비스의 처리방침이 적용됩니다.

Apple이 직접 처리하는 정보는 [Apple 개인정보 처리방침](https://www.apple.com/kr/legal/privacy/)에서 확인할 수 있습니다. Nudge의 로컬 처리와 Apple이 독립적으로 제공하는 계정·결제·운영체제 서비스의 처리를 구분해 주세요.

## 4. 앱 분석·충돌 보고와 광고

**현재 Nudge의 일반 이용자용 설정에서는 Firebase Analytics와 Crashlytics를 통한 분석·충돌 보고 전송을 활성화하지 않습니다.** 이 설명은 Firebase SDK가 앱에 포함되지 않았다는 뜻이 아니며, Apple이 자체 정책과 기기 설정에 따라 처리하는 진단 정보와도 별개입니다.

운영자는 앱의 생활 기록, 설치·선택 앱 목록, Screen Time 토큰, 야식·수면 설정 시각을 Firebase로 보내지 않습니다. 광고 제공이나 광고 개인화를 위한 IDFA·IDFV 수집, 다른 앱과 연결한 광고 추적도 사용하지 않습니다.

향후 앱 분석·충돌 보고를 도입하거나 처리 범위를 변경하는 경우 실제 항목·목적·보관기간·처리 사업자·국외 처리·권리 행사 방법을 이 방침에 반영하고, 법령상 필요한 고지와 절차를 마친 뒤 적용합니다. 이 문서의 게시만으로 해당 수집이 시작되는 것은 아닙니다.

## 5. 이메일 문의

이용자가 **latency.sprint@gmail.com**으로 문의하면 운영자는 답변과 문제 해결을 위해 다음 정보를 처리합니다.

- 회신용 이메일 주소와 이메일에 표시되는 이름
- 이용자가 보낸 문의 내용, 첨부파일, 문의·답변 일시와 처리 내용
- 이용자가 오류 설명을 위해 직접 제공한 앱·기기·운영체제 정보

기본 앱 이용을 위해 문의 메일을 보낼 필요는 없습니다. 답변에 필요한 정보를 제공하지 않으면 해당 문의의 확인·해결이 어려울 수 있습니다. 비밀번호·인증 코드·주민등록번호·카드번호·전체 생활 기록이나 다른 사람의 개인정보를 보내지 마세요. 필요한 경우에도 문제 확인에 필요한 최소 범위만 요청합니다.

문의 정보는 요청 처리와 답변에 필요한 동안 보관하고, 목적이 끝나 불필요해지면 지체 없이 삭제합니다. 법령에 따른 별도 보존 의무가 적용되는 기록은 해당 근거와 기간에 한해 따로 관리합니다. 모든 문의를 일률적으로 장기간 보관하거나 홍보용 연락처로 전환하지 않습니다.

문의 수신·답변에는 **Google LLC의 Gmail**을 이용하므로 이메일 주소·내용·첨부 및 전송 관련 정보가 Google의 서비스에서 처리·보관됩니다. 메일을 주고받는 시점에 네트워크를 통해 처리되며, Google은 전 세계 서버를 이용해 거주 국가 밖에서도 정보가 처리될 수 있다고 안내합니다. 운영자가 한국 내 저장 위치를 지정하거나 국내에만 저장된다고 보장하지 않습니다.

운영자는 필요한 문의 기록을 삭제할 때 메일과 불필요한 첨부를 함께 정리합니다. Google의 서버·백업에서 삭제가 완료되는 시점은 Google의 처리 절차와 다를 수 있습니다. 자세한 공급자 처리·보관·문의 경로는 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)을 확인하세요. 메일 이용을 원하지 않아도 앱의 기본 기능을 이용할 수 있습니다.

## 6. 웹사이트 방문

이 정책 사이트는 **GitHub, Inc.의 GitHub Pages**에서 제공합니다. 사이트에는 운영자가 설치한 방문 분석 도구·광고·외부 폰트·추적 스크립트가 없으며, 자체 회원가입이나 정보 입력 양식도 없습니다.

GitHub는 로그인 여부와 관계없이 GitHub Pages 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 안내합니다. 이 통신은 페이지를 요청할 때 발생합니다. 운영자가 Nudge의 생활 기록을 이 사이트에 올리거나 방문자의 IP를 앱 기록과 연결하지 않습니다. GitHub의 서비스 처리에는 국외 처리가 포함될 수 있으며, 보유·삭제 기준과 권리 행사 방법은 [GitHub 일반 개인정보처리방침](https://docs.github.com/ko/site-policy/privacy-policies/github-general-privacy-statement)과 [GitHub Pages 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)를 따릅니다.

정책 문서와 개정 이력은 공개되므로 고객지원 문의나 개인정보를 이 사이트의 GitHub 저장소에 공개 게시하지 말고 위 이메일을 이용해 주세요.

## 7. 제공·외부 처리와 보호 조치

운영자는 이용자의 생활 기록이나 선택 앱 정보를 판매하거나 광고 목적으로 제공하지 않습니다. 이메일 처리와 정책 사이트 제공에 사용하는 외부 서비스는 위에서 구분해 안내했으며, Apple이 직접 제공하는 서비스도 해당 설명을 따릅니다. 법령상 근거 없이 새로운 목적으로 개인정보를 제공하지 않습니다. 법령에 따라 적법한 요청을 받는 경우에는 필요한 범위를 확인해 처리합니다.

운영자는 문의 자료에 접근할 수 있는 범위를 업무상 필요한 사람으로 제한하고, 계정·기기 접근 관리와 불필요한 자료 삭제 등 보호 조치를 시행합니다. 전자자료는 사용하는 기기·서비스의 삭제 기능으로 정리하고, 법정 보존 대상 자료는 다른 용도로 이용하지 않도록 구분합니다. 운영자가 처리하지 않는 Apple·Google·GitHub의 자체 기록에 대한 요청은 각 사업자의 절차도 이용할 수 있습니다.
